# Book photos

Put your book photos here (JPG or WebP), then reference the filename in
`books.js` with the `img` field, e.g.:

    img: "annals-of-san-francisco.jpg"

Guidelines:
- Photograph the **actual copy** you're selling, not a stock image — this is
  what builds collector trust.
- Landscape-ish framing works best with the card layout (the image is
  cropped to a 5:3.4 box). A straight-on shot of the front cover is ideal.
- Keep files reasonably small (~150–400 KB). Resize to about 1000 px on the
  long edge before committing.
- If a book has no `img`, the site draws a tasteful placeholder cover, so
  it's fine to add photos gradually.
